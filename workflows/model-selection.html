二、评测维度与权重

1. 人像质量（权重最高，30%）

  • 皮肤质感：能不能保留毛孔、细纹，还是一键磨皮变塑料脸
  • 细节还原：发丝、睫毛、皮肤纹理的清晰度
  • 4K 分辨率下的稳定性：放大后有没有糊、有没有 AI 伪影
  • 测试方法：用同一段 4K 视频的正面特写帧，跑年轻化后 100% 放大对比

2. 提示词遵循（25%）

  • 能不能精准控制年轻化程度（"减龄到 25 岁"是不是真的 25 岁）
  • 能不能保留指定特征（"保留高颧骨""去法令纹但保留酒窝"）
  • 复杂提示词的理解能力（多条件叠加时会不会丢条件）
  • 参考数据：DPG-Bench 与 GenEval 分数，FLUX.1 为 83.84 / 0.78，SDXL 约 76 / 0.62

3. 角色一致性（20%）

  • 帧间一致性：同一段视频相邻 5 帧，脸是不是同一个人
  • 身份保持：年轻化后还认不认得出来是原演员
  • 难场景稳定性：侧脸、遮挡、弱光下脸崩不崩
  • 测试方法：取一段 10 秒连续镜头，抽 20 帧看脸的变化幅度

4. 生态成熟度（15%）

  • LoRA 资源：有没有现成的细节增强、人像美化 LoRA
  • ControlNet 支持：线稿、深度图、姿态控制能不能用
  • 工具链：ComfyUI 节点、批量处理工具、社区教程
  • 测试方法：查 Civitai 与 GitHub 的资源数量，实际搭一遍工作流看顺不顺

5. 推理效率（10%）

  • 单帧生成时间（512×512，20 步）
  • 显存占用（能不能批量跑）
  • 35 万帧的总耗时估算
  • 参考：SDXL 最快（6.6B），FLUX 中等（12B），Qwen 最慢（20B）

四、最终结论

选 FLUX.1 [dev]，但不是无脑选，是有取舍的。

  • 人像质量与提示词遵循是碾压级优势。这两个维度占 55% 权重，FLUX 都是最高分，影视级 4K 上线必须要这个画质。
  • 角色一致性是短板，但有解法。原生一致性一般，通过 IP-Adapter（身份保持）+ ControlNet 线稿约束 + Mask 区域限定组合解决，实测帧间脸崩率从 SDXL 的 30% 降到 5% 以下。
  • 生态够用了。FLUX 的 LoRA 与 ControlNet 生态在下半年爆发，add_detail 等关键 LoRA 已经成熟，虽然不如 SDXL 多但够用。
  • 效率问题可解。12B 参数单帧约 8–12 秒，通过 Mask 只跑人脸区域（压缩到原图 1/4 面积）+ 批量夜间处理平台，35 万帧可以在排期内完成。
  • 为什么不选 Qwen-Image：benchmark 分数高，但发布仅 2 个月，LoRA 与 ControlNet 生态几乎空白，工作流搭不起来，风险太高。
  • 为什么不选 SDXL：生态和效率最好，但人像质量与帧间一致性太差，后期去闪成本远超省下来的推理时间。
